# Timeline Block

Use `::: timeline` inside a slide with the `timeline` layout.

```markdown
<!-- _layout: timeline -->

# Roadmap

::: timeline

### Q1

**Discover**
Research and planning.

### Q2

**Build**
Implementation and testing.

### Q3

**Launch**
Release and iteration.

:::
```

Each `###` or `####` heading starts a new timeline step.
