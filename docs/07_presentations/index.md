# Presentations

Dorcs can render a Markdown page as a slide deck with Marpit-style directives and a built-in presentation layout.

## Build a deck

1. Add `presentation: true` in front matter.
2. Separate slides with `---`.
3. Add optional directives at the top of each slide.
