# Markdown Basics

Dorcs supports the Markdown features most docs sites need out of the box.

## Headings

```markdown
# Page title
## Section
### Subsection
```

Headings are used to build the table of contents automatically.

## Lists

```markdown
- unordered
- lists

1. ordered
2. lists
```

## Links

```markdown
[Guide](./guide.md)
[External site](https://example.com)
```

## Code

````markdown
```go
fmt.Println("hello")
```
````

## Tables

```markdown
| Name | Role |
| --- | --- |
| API | Public |
| Admin | Internal |
```

## Blockquotes and rules

```markdown
> Important note

---
```
